Pengaturan koneksi database

Project URL sudah diisi berdasarkan project reference Criminology Lab. Masukkan hanya publishable key atau anon public key dari Supabase Settings → API Keys. Jangan pernah memasukkan service_role/secret key.

Project URL dan publishable key Criminology Lab sudah disediakan. Kunci publik aman digunakan di browser; jangan pernah masukkan service-role/secret key.

Login kurator / administrator

Akun harus sudah terdaftar di Supabase Auth dan memiliki role curator atau admin pada public.observatory_members.
